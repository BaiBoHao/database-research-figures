# Database and systems icons

These 20 unmodified SVG files come from [Lucide 0.468.0](https://github.com/lucide-icons/lucide/tree/0.468.0/icons). The [upstream license](LICENSE) and copyright notice apply to the SVGs. Preserve the notice if you recolor or convert the icons into another editable vector format.

| Role | Icon files |
| --- | --- |
| Database, backup, and storage | `database.svg`, `database-backup.svg`, `hard-drive.svg`, `table-2.svg` |
| Hosts and resources | `server.svg`, `cpu.svg`, `container.svg` |
| Requests and connections | `route.svg`, `network.svg`, `filter.svg`, `plug.svg`, `search.svg` |
| Replication and orchestration | `repeat-2.svg`, `arrow-left-right.svg`, `workflow.svg`, `sliders-horizontal.svg` |
| Telemetry, logs, latency, and faults | `activity.svg`, `file-text.svg`, `timer.svg`, `circle-alert.svg` |

Database roles such as primary and replica should have text labels. Use the same line icon for instances of the same kind, and keep icons visually subordinate to the paths and labels.
