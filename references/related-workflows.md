# Related drawing workflows

Read the original project when you need more detail. These references are optional and do not change the requested drawing format or grant access to an external service.

| Upstream reference | Practice to borrow |
| --- | --- |
| [FigureCraft](https://github.com/zlsjtj/FigureCraft) | Give colors a stable meaning and use the drawing itself to explain relationships. |
| [research-figure](https://github.com/kissshhot/research-figure) | Choose a diagram structure based on the research question and check the result at publication size. |
| [sci-figure](https://github.com/xiao-yuling/sci-figure) | Use restrained type, legible axes, and reproducible scripts for results plots. |
| [open-research-skills](https://github.com/gxCaesar/open-research-skills) | Distinguish explanatory schematics from measured results and keep the figure editable. |
| [ProcessOn Skills](https://github.com/processonai/processon-skills) | Use the editor and its documented interface when you need native ProcessOn workflows. |

A useful review sequence is to check entities and endpoints first, then layer boundaries and reading order, then typography and color, and finally the editable source at the intended size.
